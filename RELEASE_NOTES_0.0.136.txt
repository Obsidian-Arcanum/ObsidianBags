Obsidian Bags 0.0.136 — Bank One Stack Pop-out Parity
Target: WoW Forever 1.60.1 / Interface 16001
Evidence: Locally validated, NOT YET CLIENT-VERIFIED
Rollback: ObsidianBags-0.0.135.zip (client-confirmed through bank Sort & pop-out functionality)

Changes
-------
* Bank One Stack pop-out now visually matches the carried-inventory pop-out:
  - Compact gold-bordered dark panel and familiar close X.
  - Item name above the "N physical stack(s) | TOTAL total" subtitle.
  - Five-across grid of full-size item icons, with individual physical stack counts.
  - Scrolls when more than four grid rows are present; no visible scrollbar.
  - No diagnostic bank bag/slot coordinates or bulky "Stack 1" row captions.
  - Bank-owned slot art/count font/quality styling retained.
* Left-click selects/highlights an individual real bank stack without turning off
  Bank One Stack or expanding/collapsing the bank view.
* Right-click withdrawal and Shift-left split still call existing guarded bank
  actions and use the same verified physical-stack token/index identity.
* A dragged bank pop-out icon now enters the SAME verified bank ghost drag
  coordinator as an ordinary bank slot. No native container button script or
  real cursor is synthesized by the popup. Supported destinations include
  eligible visible bank cells, main bag targets via the existing guarded
  bank-to-bag transfer coordinator, and another physical popup icon for
  verified exact-target merges/virtual-only positional moves.
* Releases over popup blank space never fall through onto a bank button under
  the popup. Popup target identity is checked against current saved tokens.

Safety / unchanged
------------------
* BankModel.lua, CrossTransfer.lua, StackWork.lua, physical move/plan/batch,
  BankCategoryView.lua, all combat modules and main StackPopover.lua unchanged.
* Bank Sort remains visual-only and working in both Standard/Category Views.
* No settings, profile schema, SavedVariables or dependency changes.
* No combat-specific bank code added.

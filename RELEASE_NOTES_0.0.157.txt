Obsidian Bags v0.0.157 | Integrated combat pickup cancellation

The native ClearCursor() cancellation path tested in v0.0.156 is enabled by
 default when expanded inventory enters combat. It returns a recorded normal
(non-Shift) native item pickup to its source on blank background click or
mouse-release/drag-receive, rather than requiring right-click cancellation.

The v0.0.153 native exact-empty physical-slot split-deposit path remains
unchanged. Cancellation never deliberately runs for captured Shift splits.
No bank, sorting, profile, SavedVariables, or secure item-button click/drag
handler behavior is modified.

/obcombatdrop status       inspect both independent counters
/obcombatdrop cancel off   disable ONLY cancellation; split deposits remain
/obcombatdrop off          disable both session-only (outside combat)
/obcombatdrop on           re-enable both session-only (outside combat)

v0.0.157 is locally tested; new always-on integration needs Forever client QA.
